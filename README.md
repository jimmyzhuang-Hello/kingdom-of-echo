Running the Game
Run the executable from the project root directory:game.

W/A/S/D to move（use caps lock）

Project Overview
This project is an interactive application based on the C language. Currently, window initialization and basic movement functions have been completed. In the future, a dialogue system and a scene switching module are planned to be added. Due to technical difficulties in multi - person collaboration and integration, only the core interactive part can be run at present.
Current Functions and Limitations

Functions Implemented
Window Initialization: Create a window of a fixed size that supports the close operation.
Basic Movement: Control the character to move within the window using the directional keys (WASD). Boundary detection prevents the character from moving out of the screen.

Functions to be Implemented
Dialogue System: It is planned to support text display, option selection, and branching storylines.
Scene Switching: Implement the loading and transition of different scenes (such as rooms and maps).

Known Limitations
During multi - person collaboration and integration, some modules (such as the dialogue system) have not been merged and cannot be run for the time being.
The movement logic only supports simple two - dimensional coordinate updates, without animation or collision detection optimization.
